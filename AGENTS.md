# Repository safety and routing

- Never read, print, stage, or commit `src/sections/header.private.tex` or `content/master/`.
- Never invent candidate facts, metrics, skills, job details, or application status.
- Keep real job packages and generated PDFs out of version control unless the owner explicitly changes the privacy policy.
- Local validation and disposable builds are safe to run without additional approval.
- Read only the rule document relevant to the task.

| Task | Read |
|---|---|
| Add or update a job target | `docs/rules/targets.md` |
| Build or inspect PDFs | `docs/rules/build.md` |
| Change repository structure | `docs/rules/structure.md` |
