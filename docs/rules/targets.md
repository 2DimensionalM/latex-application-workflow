# Target workflow

Create one untracked `targets/<slug>/` directory per role with `metadata.yaml`, `jd.md`, `notes.md`, and `tailoring.md`.

Use a unique quoted three-digit `internal_id`. Leave version paths empty until their files exist. Update `PROJECT_STATUS.md` from verified facts; building a document never implies that an application was submitted.

The committed example is a schema template, not an application record.
